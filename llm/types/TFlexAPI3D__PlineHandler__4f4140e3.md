# PlineHandler

Assembly: `TFlexAPI3D`

## Summary

Класс, обеспечивающий доступ к полилинии

## Methods

### `Instance`

ID: `M:PlineHandler.Instance`

Хэндлер полилинии для локального трэда

Remarks: Общая схема: Есть пул полилиний. Хэндлер для работы с полилинией объявлен как thread_local, что означает, что при первом обращении к нему в текущем трэде у него вызывается конструктор по умолчанию, а при завершении трэда - вызывается деструктор. В конструкторе хэндлер получает полилинию из пула, а в деструкторе - возвращает ее.
