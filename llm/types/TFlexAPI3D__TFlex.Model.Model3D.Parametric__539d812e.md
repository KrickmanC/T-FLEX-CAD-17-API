## Propertys

### `Number`

ID: `P:TFlex.Model.Model3D.Parametric.Number`

Переменная номера копии

Remarks: Значение для переменной устанавливается в процессе пересчёта от единицы до требуемого количества копий. Как правило, от переменной в номере копии зависит форма и положение исходного объекта. Поскольку номер копии изменяется в процессе пересчёта, то переменная может быть только независимой. Это обязательный параметр

### `Quantity`

ID: `P:TFlex.Model.Model3D.Parametric.Quantity`

Количество копий

Remarks: Количество копий должно быть больше одного. Количество копий округляется до ближайшего целого, меньшего заданного

### `SourceLCS`

ID: `P:TFlex.Model.Model3D.Parametric.SourceLCS`

Исходная система координат

Remarks: К каждой копии применяется преобразование из исходной системы координат в текущую, которая может быть расчитана по пути или задана явными функциональными зависимостями от номера копии. Исходная система координат может быть задана явно. Если исходная ЛСК не задана, то в качестве исходной ЛСК используется ЛСК первой копии
